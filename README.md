Graph-Based Machine Learning for Attack-Path Vulnerability Prioritization

Research Overview

This repository accompanies the research manuscript Graph-Based Machine Learning for Attack-Path Vulnerability Prioritization.

The study examines the potential of graph neural networks (GNNs) to improve vulnerability prioritization by incorporating network topology, asset dependencies, identity relationships, and privilege transitions.

Comparative Framework

The research compares four prioritization approaches:

- Graph Neural Network (GNN)
- XGBoost
- Random Forest
- Common Vulnerability Scoring System (CVSS)

The illustrative experimental scenario comprises 1,250 viable attack paths, 100 designated critical assets, and 80 initially reachable critical assets.

Research Documentation

The Excel workbook contains manuscript-aligned tables covering predictive classification, remediation budgets, attack-path elimination, critical-asset reachability, residual exposure, and remediation efficiency.

Reproducibility and Validation

The numerical benchmarks are illustrative manuscript-reported values and have not been independently validated through publicly available experimental records.

The repository currently provides research documentation rather than a complete executable reproducibility package. Underlying graph datasets, model-training code, experiment configurations, and independently generated results are needed to establish empirical reproducibility.

Research Focus

Graph machine learning, vulnerability prioritization, attack graphs, cybersecurity exposure management, and risk-informed remediation.
